# Event Summary Report: "FCAJ x AABW Cloud Workshop & Career Networking"

---

### 1. Purpose of the Event

- **Community Building**: Bridging FCAJ Cloud interns, students, and senior cloud engineers from AWS partner ecosystems.
- **Modern Cloud Insights**: Exploring state-of-the-art cloud architecture, network security, CI/CD automation, and Serverless computing on AWS.
- **Career Orientation**: Learning real-world experiences from multi-national tech firms, AWS certification roadmaps (Associate & Professional levels), and interview strategies.
- **Architectural Mindset**: Analyzing real-world challenges in system scalability, FinOps (cost management), and High Availability / Fault Tolerance designs.

---

### 2. Speaker List

- **Mr. Minh Triet**: Senior Solutions Architect at AWS Partner - System Architecture & FinOps Specialist.
- **Ms. Nhat Ha**: Cloud Security & Compliance Specialist - Cloud Security Expert.
- **Mr. Thanh Tung**: Lead DevOps Engineer - Infrastructure Automation & Kubernetes on AWS (EKS) Lead.
- **FCAJ & AABW Steering Board Members**: Event coordinators, mentors, and student networking leads.

---

### 3. Highlighted Topics

#### Topic 1: AWS Modern Cloud Architecture & Trends (Mr. Minh Triet)
- **Infrastructure Evolution**: Shifting from legacy On-Premises environments to Hybrid Cloud and Cloud-Native paradigms.
- **6 Pillars of AWS Well-Architected Framework**:
  1. *Operational Excellence*
  2. *Security*
  3. *Reliability*
  4. *Performance Efficiency*
  5. *Cost Optimization*
  6. *Sustainability*

#### Topic 2: Infrastructure as Code (IaC) & DevOps Automation (Mr. Thanh Tung)
- **Infrastructure as Code (IaC)**: Automated provisioning and version control using Terraform and AWS CloudFormation.
- **Containerization & Orchestration**: Deploying Microservices on AWS EKS (Kubernetes) and AWS Fargate.
- **DevSecOps Integration**: Automating security vulnerability scanning within CI/CD pipelines using AWS CodePipeline and GitHub Actions.

#### Topic 3: Cloud Security & Identity Governance (Ms. Nhat Ha)
- **Shared Responsibility Model**: Differentiating security responsibilities between AWS and Customers.
- **IAM Best Practices**: Implementing Least Privilege, IAM Roles, Multi-Factor Authentication (MFA), and AWS SSO.
- **Data Protection**: Leveraging AWS CloudTrail for auditing, Amazon GuardDuty for threat detection, and AWS KMS for encryption.
